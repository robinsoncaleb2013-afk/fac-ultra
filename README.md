# FAC Ultra

Painted fishing incremental. Fifteen waters, 375 species, a live strike minigame, gear, boss lairs, an aquarium that earns while you sleep, contracts, and rebirth — plus sandbox, local and online co-op, derby, and boss-rush modes.

Stack: React, TypeScript, TanStack Start, Zustand, Tailwind.

## Run

```bash
npm install
npm run dev
```

Progress saves in the browser (`localStorage`). Biome paintings live in `public/art/biomes`.
