# FAC Ultra

Painted fishing incremental. Ten waters, a live strike minigame, gear, a dex, contracts, and rebirth.

Stack: React, TypeScript, TanStack Start, Zustand, Tailwind.

## Run

```bash
npm install
npm run dev
```

Progress saves in the browser (`localStorage`). Biome paintings live in `public/art/biomes`.
