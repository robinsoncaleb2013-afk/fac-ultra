# Map

The readable diagram of how this whole game connects lives in
[`docs/relational-map/`](relational-map/README.md) — start with its
README for the one-picture overview, then the per-area files
(runtime and routes, game and data, server and accounts,
external connections).

For the design contract itself see
[`docs/architecture/`](architecture/README.md) — its
[codebase map](architecture/02-codebase-map.md) says where things
live and where new work plugs in. The docs index is
[`docs/README.md`](README.md), the known gaps are collected in
[`docs/KNOWN-GAPS.md`](KNOWN-GAPS.md), and the rules that keep this
map honest are in [`docs/RULES.md`](RULES.md).
