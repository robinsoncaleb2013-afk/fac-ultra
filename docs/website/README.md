# Caleb's website docs — read this first

This folder is the standing instructions for keeping Caleb Robinson's pages
on www.robinsonaisystems.com current. It exists so that **any** AI agent
helping Caleb — in this repo or any of his future projects — can be pointed
here once and know the whole system.

**Caleb: if an agent is helping you and seems unsure about your website,
tell it:** *"Read the website docs in my fac-ultra repo, docs/website,
starting with the agent playbook."* (Once the hub repo exists — see
HUB-SETUP.md — the same words work there, and that becomes the canonical
home.)

## Read in this order

1. `AGENT-PLAYBOOK.md` — the contract and the workflows. Agents: this is
   your operating manual; read it before touching any website-related file.
2. `START-HERE-CALEB.md` — the same system in plain words, written for
   Caleb. Match your explanations to it.
3. `project-page-template.md` — the blank website record every project
   carries at `docs/project-page.md` in its own repo.
4. `new-project-checklist.md` — the bootstrap an agent runs when any new
   project starts, so its website page is set up as part of the project,
   not bolted on later.
5. `HUB-SETUP.md` — the plan for the `caleb-projects` hub repo: the single
   registry/front door for all of Caleb's projects once it is created.

The website-side rules (Chris's repo) are in the `robinson-ai-systems`
repo's `docs/WEBSITE-BLUEPRINT.md`, "The Caleb Robinson projects section".
If anything here ever disagrees with that blueprint, the blueprint wins and
the difference gets reported to Chris.
